## 三、「后缀」到底影响什么

后缀 = 这个 Apple ID 是用什么邮箱注册的。它不影响你登录 App Store、不影响下载应用、不影响能不能转区。它影响的是两件事：**找回路径**和**被回收的风险**。

- **gmail / hotmail / 163 / QQ 后缀**：主流邮箱。如果卖家把邮箱一起给你（含邮箱密码），你就能自己改 Apple ID 密码、自己接管找回流程，安全性最高。如果只给 Apple ID 不给邮箱，那这个号的实际控制权仍在卖家手里。
- **iCloud 后缀**：注册邮箱就是 Apple 自己的 iCloud 邮箱。这类号通常无法把邮箱交给你，改密/找回只能通过密保问题，所以卖家会标「带密保」——**密保答案是你能不能接管这个号的唯一凭证**。
- **「邮改纯白」「真机注册」这类标注**：说的是注册方式（改过邮箱 / 真机注册），不是质量等级，别当成加分项单独付费。

⚠️ 一句话结论：**买号真正买的是「能不能自己改密码」。**带邮箱密码 > 带密保答案 > 什么都不带。下单前问清这三样给哪个，比纠结后缀有用得多。

## 五、下单前必查 7 条（防坑清单）

1. **商品页写没写注册年份**。只写「老号」不写年份的，等于没写规格。
2. **写没写后缀类型**。gmail / QQ / iCloud 差别很大，不标就是不想让你比价。
3. **是否标注「可转区」**。不可转区的号，以后想换区只能再买一个。
4. **给不给邮箱密码 / 密保答案**。这是决定你能不能真正拥有这个号的唯一标准。
5. **发货方式**。自动发货（付款后页面直接出账号）比人工发货可靠，深夜也能拿到。
6. **售后条款原文**。重点看「交付时即无效」能不能补发，以及是否支持「用几天后被锁」的补发——后者几乎没有店会承诺，别信口头承诺。
7. **有没有实时库存显示**。库存为 0 还能下单的，多半是超卖，会卡在「已付款待发货」。

## 七、常见问题

### Q：¥10 的号和 ¥25 的号，除了小火箭还有什么区别？

没有别的区别。账号本身都是普通 Apple ID，差别只有「有没有买过 Shadowrocket」。如果你已经能用别的号下载小火箭，就没必要买成品号。

### Q：买来发现密码错误怎么办？

先确认没有多余空格、没有把密保答案当密码。仍不行就是交付问题，直接走订单内售后，不用先跟客服掰扯——条款写的是「交付时无效可补发或退款」。

### Q：能改成我自己的邮箱吗？

可以，前提是你拿到了这个号的完整控制权（邮箱密码或密保答案），并且能登录 Apple ID 管理页。只有账号密码、没有邮箱也没有密保的号，改不了。

### Q：买号和自己注册，哪个更稳？

自己注册的更稳，因为从头到尾只有你一个人知道。但你得解决美国地址、有时还要处理付款验证。买号省事，代价是「这个号有历史，原来的持有人理论上可能找回」——这是买号这个模式的固有风险，任何店都消除不了，只能靠「给你邮箱/密保」来降低。

### Q：只想免费下一个小火箭，需要买吗？

不需要。共享号就够用，用完退出即可。判断标准很简单：**只用一次 → 共享号；要长期用、要恢复购买 → 买号。**
