一、先分清楚你买的是哪一种

搜「苹果id购买」（也有人写「苹果 ID 购买」「买苹果id」）的人，需求其实分三类，价格差一倍以上。买错类型是绝大多数纠纷的来源。先对号入座，再谈价格。

1. 裸老号（各区都有，¥10 起）

只有账号密码，不含任何已购应用。注册年份、注册邮箱后缀、能不能转区，是这类号的全部差别。适合：已经有小火箭（或压根不需要）、只是想有一个外区账号用来下载别的应用、注册服务。

2. 成品号（带小火箭已购，¥25 左右）

账号里已经买过 Shadowrocket，登录后可以直接在「已购项目」里下载，不用再付一次 $2.99。小火箭是买断制、跟账号走，所以「带已购」这件事本身有成本，成品号贵在这一点，不在账号本身。适合：目的就是用小火箭、不想自己折腾付款的人。

3. 可转区号

账号当前在 A 区，但满足 Apple 的转区条件（无余额、无订阅、无未完成订单），可以自己改到别的区。适合：不确定长期用哪个区、或者以后想换区买应用的人。注意「可转区」是满足条件，不是「已经转好」，转区操作仍需你自己完成。

三、「后缀」到底影响什么

后缀 = 这个 Apple ID 是用什么邮箱注册的。它不影响你登录 App Store、不影响下载应用、不影响能不能转区。它影响的是两件事：找回路径和被回收的风险。

  • gmail / hotmail / 163 / QQ 后缀：主流邮箱。如果卖家把邮箱一起给你（含邮箱密码），你就能自己改 Apple ID 密码、自己接管找回流程，安全性最高。如果只给 Apple ID 不给邮箱，那这个号的实际控制权仍在卖家手里。
  • iCloud 后缀：注册邮箱就是 Apple 自己的 iCloud 邮箱。这类号通常无法把邮箱交给你，改密/找回只能通过密保问题，所以卖家会标「带密保」——密保答案是你能不能接管这个号的唯一凭证。
  • 「邮改纯白」「真机注册」这类标注：说的是注册方式（改过邮箱 / 真机注册），不是质量等级，别当成加分项单独付费。

⚠️ 一句话结论：买号真正买的是「能不能自己改密码」。带邮箱密码 > 带密保答案 > 什么都不带。下单前问清这三样给哪个，比纠结后缀有用得多。

五、下单前必查 7 条（防坑清单）

  1. 商品页写没写注册年份。只写「老号」不写年份的，等于没写规格。
  2. 写没写后缀类型。gmail / QQ / iCloud 差别很大，不标就是不想让你比价。
  3. 是否标注「可转区」。不可转区的号，以后想换区只能再买一个。
  4. 给不给邮箱密码 / 密保答案。这是决定你能不能真正拥有这个号的唯一标准。
  5. 发货方式。自动发货（付款后页面直接出账号）比人工发货可靠，深夜也能拿到。
  6. 售后条款原文。重点看「交付时即无效」能不能补发，以及是否支持「用几天后被锁」的补发——后者几乎没有店会承诺，别信口头承诺。
  7. 有没有实时库存显示。库存为 0 还能下单的，多半是超卖，会卡在「已付款待发货」。

六、交付和售后实际是什么流程

以该店服务条款原文为准，这类数字商品店的通行规则是：

  • 自动发货：支付成功后系统直接出账号密码，不走人工。所以「付款了没人理」通常不是发货问题，而是支付回调没成功——先查订单状态，再找客服。
  • 不支持七天无理由：数字商品一经交付即可复制，这是行业惯例，不是某家苛刻。但「交付时就是无效号 / 与标注严重不符」属于另一回事，可以申诉。
  • 售后边界：交付时无效 → 补发或退款；用了几天被 Apple 风控锁 → 通常只能协商，因为无法区分是号的问题还是使用方式的问题（比如登了 iCloud、频繁切换设备）。
  • 客服时段：该店标注 09:00–23:00（UTC+8），Telegram 联系，通常 10 分钟内回。深夜下单遇到问题，等到早上是正常的。

⚠️ 有一条必须自己守住：买来的号只在 App Store 登录，绝不登 iCloud / 设置。登录 iCloud 会触发激活锁，这是唯一会造成真实设备损失的操作，而且和账号是不是买的无关，是 iOS 的机制。

七、常见问题

Q：¥10 的号和 ¥25 的号，除了小火箭还有什么区别？

没有别的区别。账号本身都是普通 Apple ID，差别只有「有没有买过 Shadowrocket」。如果你已经能用别的号下载小火箭，就没必要买成品号。

Q：买来发现密码错误怎么办？

先确认没有多余空格、没有把密保答案当密码。仍不行就是交付问题，直接走订单内售后，不用先跟客服掰扯——条款写的是「交付时无效可补发或退款」。

Q：能改成我自己的邮箱吗？

可以，前提是你拿到了这个号的完整控制权（邮箱密码或密保答案），并且能登录 Apple ID 管理页。只有账号密码、没有邮箱也没有密保的号，改不了。

Q：买号和自己注册，哪个更稳？

自己注册的更稳，因为从头到尾只有你一个人知道。但你得解决美国地址、有时还要处理付款验证。买号省事，代价是「这个号有历史，原来的持有人理论上可能找回」——这是买号这个模式的固有风险，任何店都消除不了，只能靠「给你邮箱/密保」来降低。

Q：只想免费下一个小火箭，需要买吗？

不需要。共享号就够用，用完退出即可。判断标准很简单：只用一次 → 共享号；要长期用、要恢复购买 → 买号。
